# Jacnex Studio

Instala, abre y actualiza todas las apps de Jacnex desde un solo lugar.

Descargas: [versiones publicadas](https://github.com/jacnexstudio/jacnex-studio/releases).

Basado en [ArtCraft Launcher](https://github.com/storytold/craft-launcher) (MIT o Apache-2.0), con la
marca Jacnex. Cómo se compila: [jacnex-build](https://github.com/jacnexstudio/jacnex-build).
Jacnex no está afiliado ni respaldado por el ArtCraft Team.
